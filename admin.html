PAGES CMS

從同一個後台管理整個網站

可修改首頁、宮主、電子書、影片、募捐案例、成果相簿、祈安服務、參拜指南、Facebook、聯絡方式與頁尾。

進入內容後台 →
  1. 登入使用擁有網站資料庫的 GitHub 帳號登入 Pages CMS。
  2. 選擇網站開啟天聖宮網站資料庫，再選「天聖宮網站全部內容」。
  3. 修改內容展開要修改的區塊；文字直接輸入，照片使用圖片選擇器上傳或更換。
  4. 儲存發布按儲存後，GitHub 會保留修改紀錄，Cloudflare Pages 會自動更新。
不會改到版型

後台只開放文字、圖片、影片、連結與地址欄位；網站排版、動畫與跨裝置樣式仍維持第 50 版。
